==============================================================================
1. INTRODUCTION                                          *pastel-introduction*

    pastel.vim previews the color under the cursor: move the cursor onto a
    color code, such as #FF8800, and a small popup shows that color, on the
    backgrounds of your choice. The popup goes away when the cursor leaves the
    code or you enter insert mode.

==============================================================================
2. REQUIREMENTS                                          *pastel-requirements*

    - Vim 8.1.1553 or newer, built with |+popupwin|, |+textprop| and |+eval|
    - A GUI, or a terminal with 'termguicolors' enabled

    Without these, the plugin does nothing, and does not raise errors.

==============================================================================
3. NOTATIONS                                                *pastel-notations*

    These color codes are recognized:

    - #RGB, #RRGGBB, #RGBA and #RRGGBBAA; the last also as #AARRGGBB, SEE
      |g:pastel_alpha_position|
    - rgb(), rgba(), hsl(), hsla(), hwb(), hwba(), hsv() and hsva(), in upper
      or lower case, in the comma notation, as in rgb(255, 0, 0, 0.5), and the
      space and slash one, as in rgb(255 0 0 / 50%); hwb() has no comma
      notation, as in CSS

    A hexadecimal code must not be preceded or followed by a letter, digit or
    underscore, so that eg. "#define" is not taken for a color. A function
    with a mistake, eg. a missing component, is ignored.

    A color with an alpha channel is shown blended over each background: on
    black it looks darker, on white lighter, and on the checkered background
    the checkers show through.

    Lines longer than 'synmaxcol' (0 means no limit) are not searched, as that
    would slow down moving the cursor in minified or machine-generated files.

==============================================================================
4. OPTIONS                                                    *pastel-options*

    All options are global variables, set in your vimrc or at any time later
    with :let; a change takes effect the next time the popup is shown.

g:pastel_color_mode  (default "k")                       *g:pastel_color_mode*
    The previews to show and their layout: a string of block letters, left to
    right, with these meanings:

    - k: the color on black
    - w: the color on white
    - t: the color on a checkered "transparent" background
    - 2: the color on black and white, alternating, SEE |g:pastel_color_timer|
    - 3: the color on black, checkered and white, alternating, in that order
    - a bar: the blocks after it go in a new row below

    Examples: >
        let g:pastel_color_mode = 't'     " one checkered block
        let g:pastel_color_mode = 'kw'    " black and white, side by side
        let g:pastel_color_mode = 't|kw'  " checkered, with both below
<

    The text under the empty part of a layout, eg. right of a shorter row,
    stays visible. Any other value prints a warning; when set later, the
    previous layout stays.

g:pastel_color_timer  (default 5)                       *g:pastel_color_timer*
    Seconds between the backgrounds of the 2 and 3 blocks changing, 0.1 or
    more. A smaller value turns alternating off.

g:pastel_color_size  (default 6)                         *g:pastel_color_size*
    Size of the color block, vertically in half-characters and horizontally in
    characters, so that it looks square.

g:pastel_bg_size  (default 2)                               *g:pastel_bg_size*
    Size of the margin around the color block, in the same units.

g:pastel_alpha_position  (default "auto")            *g:pastel_alpha_position*
    Where the alpha is in 8-digit hexadecimal codes:

    - "last": #RRGGBBAA, as in CSS
    - "first": #AARRGGBB, as in Android
    - "auto": "first" in the filetypes of |g:pastel_alpha_first_filetypes|,
      "last" in the others, with a short note the first time an 8-digit code
      is found in a buffer

    The 4-digit form is always #RGBA.

b:pastel_alpha_position                              *b:pastel_alpha_position*
    If set, it takes precedence over |g:pastel_alpha_position| in its buffer.
    Example: >
        autocmd FileType cs let b:pastel_alpha_position = 'first'
<

                                              *g:pastel_alpha_first_filetypes*
g:pastel_alpha_first_filetypes  (default ['java', 'kotlin'])
    The filetypes where the "auto" of |g:pastel_alpha_position| means "first".

g:pastel_ignore_filetypes  (default [])            *g:pastel_ignore_filetypes*
    The filetypes where no colors are looked for, eg. ['sql'] for its very
    long lines, or ['gitcommit'], where #123 is an issue and not a #RGB color.

g:pastel_offset_x  (default 2)                             *g:pastel_offset_x*
    Horizontal placement of the popup relative to the color code, in
    characters: positive is right of the code, that many columns after its
    last column; negative is left of the code; 0 is centered on it.

g:pastel_offset_y  (default 0)                             *g:pastel_offset_y*
    Vertical placement relative to the cursor line, in lines: positive is
    below, negative is above, 0 is centered on the line.

    If the popup does not fit on the screen at the requested offset, the
    offset is inverted, eg. 2 becomes -2. With no room on either side of the
    code, the popup goes below the line, or above it. A popup larger than the
    screen is clipped, and a warning is shown once.

g:pastel_black_bg  (default "#000000")                     *g:pastel_black_bg*
    The color of the black background.

g:pastel_white_bg  (default "#FFFFFF")                     *g:pastel_white_bg*
    The color of the white background.

g:pastel_trans_fg  (default "#BFBFBF")                     *g:pastel_trans_fg*
    The light color of the checkered background.

g:pastel_trans_bg  (default "#404040")                     *g:pastel_trans_bg*
    The dark color of the checkered background.

==============================================================================
5. KNOWN ISSUES                                                *pastel-issues*

    - In Vims older than 8.2.4713, which lack the |WinScrolled| event,
      scrolling the window without moving the cursor leaves the popup at its
      old position on the screen.
    - In Vims older than 8.1.1580, which lack |popup-mask|, the empty part of
      a layout, eg. right of the shorter row of 'wk|t', hides the text under
      it. A single row of blocks is not affected.
